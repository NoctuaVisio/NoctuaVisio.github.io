Conectar GitHub
Cola um fine-grained Personal Access Token com permissão de escrita neste repo. Depois disso, Gerar Link Cliente faz commit do JSON automaticamente — você só copia o link e manda pro cliente.
Como gerar:
1. Abre github.com/settings/personal-access-tokens/new
2. Token name: Noctua Admin · Expiration: 90 days (ou mais)
3. Resource owner: NoctuaVisio
4. Repository access: Only select repositories → NoctuaVisio.github.io
5. Repository permissions → Contents: Read and write
6. Generate token → copia e cola abaixo
